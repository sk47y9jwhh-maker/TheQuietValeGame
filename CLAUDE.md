# The Quiet Vale handover

Read [CLAUDE_HANDOFF.md](CLAUDE_HANDOFF.md) before continuing this branch.
This is `codex/claude-code-handoff`, an uploaded review and authoring handoff.
Living Table is the only selected alternative layout. The classic layout is a
comparison baseline; the live site still comes from `main`.

Physical rules authority remains the approved, locked v6.6 package. The v6.8
rulebook and v6.7 Steward aids are the latest review documents, not a new approval.
Preserve the locked archive and its manifest. For new document edits, start
from the latest editable source and create a separately versioned output.

Run `npm test` and `npm run build` after application changes. Downloads,
checksums, document tooling, known limits and the recommended next work are
documented in the handoff. Historical holiday notes describe earlier candidates
and a completed automation; they are evidence, not an active work schedule.
