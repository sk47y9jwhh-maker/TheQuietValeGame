# The Quiet Vale — project handoff

This release makes the selected local work available to Claude Code and other repository collaborators. Start with [CLAUDE_HANDOFF.md](https://github.com/sk47y9jwhh-maker/TheQuietValeGame/blob/codex/claude-code-handoff/CLAUDE_HANDOFF.md) on branch `codex/claude-code-handoff`.

Included archives:

- Latest local four-board print pack and standard box print pack.
- Original approved, locked v6.6 printed rules ZIP, unchanged.
- Latest polished v6.8 rulebook PDF and editable DOCX, unchanged.
- Latest six v6.7 Steward aids, explicitly compatible with v6.8.
- Rulebook authoring inputs and original source snapshots; portable authoring scripts are tracked on the handoff branch.

The branch includes Living Table as the only alternative playable layout, plus the classic comparison baseline and design/testing evidence. It passes 692 tests and the production build. The v6.8 editorial and original-PDF fidelity audits pass; archive hashes are listed in SHA256SUMS.txt and release-assets.json.

v6.6 remains approved. The v6.8 rulebook and v6.7 guides remain review editions. This handoff is marked as a prerelease because it includes an alternative UI concept; publishing it does not deploy that concept or approve the newer rules.

The six archives total approximately 1.15 GB. The handover provides selective downloads and a checksum-verifying extraction helper. Board/box files are the latest local production candidates; current manufacturer dielines and physical proof approval have not been rechecked.
